# 稳忆 SteadyMem

**固定预算下递归工作记忆的持续更新与关联保持。**

SteadyMem 研究：模型持续接收信息、写入时尚不知道未来具体问题，在固定持久记忆预算内，如何使新事实可用、合法修订生效，并保住其他仍然有效的关联。当前应用范围为长任务 Agent 的有限工作记忆，重点是工具观察、项目配置和任务约束的持续维护。

项目工作区固定为 `/mnt/bn/ecom-cyq-redirect/liuzhonglie/SteadyMem`。后续代码、配置、数据清单、实验结果与研究记录均在本目录中组织；代码在共享工作区编写，计算任务使用远端 8 张 H100 服务器。

## 当前状态

截至 2026 年 10 月 13 日，已完成研究讨论归档、飞书原稿保存和远端共享目录验证。尚未实现或执行 SteadyMem 新算法实验，本文档中的提升目标均不是已取得的结果。

研究顺序为：**确认有实际意义的失败 → 定位机制 → 选择干预 → 严格同预算验证 → 检验任务价值。** KDA 是研究载体；A、B、C 是条件候选。B 的有限干扰反馈调度可作为首个短期筛选候选，但必须先与同预算静态、哈希和内容路由比较，不能预设它是最终方案。
